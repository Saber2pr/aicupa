What aicupa / Todo List can do

From AI-assisted planning on the web to classic TreeView editing everywhere, the bullets below track the public TodoList Pro usage documentation (Markdown guides under Usage and About). Same product family across web, VS Code, and desktop builds—availability can vary by host, version, and license tier; use the guides for exact menus and prerequisites.

Plan & capture

Tree

TreeView and .todo files

Edit structured todos in a hierarchy of *.todo JSON files. Keep parent context next to sub-tasks so large goals stay navigable.

Calendar

Calendar views and time ranges

Attach time ranges to items and schedule in a calendar view. Pair dates with the tree so planning and execution live together.

Timeline

Ordered “today” lane

When the list gets noisy, use the timeline: unlock, pick tasks in the order you want to run them, see them chained above the tree, then lock again. Repeat a pick to remove it from the sequence.

Import

Paste to create branches

Copy text from another document, select a parent node, paste (or use the documented context action) to generate multiple todo items in one step.

Stay organized

Priority

Sort by priority

Assign priorities, run a sort from the view menu, and optionally turn on automatic sorting after each edit so the list reorders itself.

Progress

Progress in the UI

Surface overall progress where the host integrates it—for example via the status bar in VS Code-style environments. Behavior depends on the client you install.

Look & feel

Themes and languages

Follow the active editor theme when supported. The published language list includes English, Chinese (Simplified and Traditional), Japanese, Korean, German, French, Spanish, Italian, Portuguese (Brazil), Russian, and Turkish—choose yours in settings.

Background

Custom background image

Decorate the editor with a background (documented from v0.2.86 onward). In VS Code the guide references remote image URLs; local files are called out for the desktop build.

Automate & publish

AI

AI execution

Configure an AI Command template in Settings (use $cmd for the generated prompt). Trigger the robot control on a todo to open a terminal, hand work to your CLI agent, and let file updates refresh the tree as tasks complete.

Export

Markdown and HTML table

Turn the tree into a readable Markdown article or wiki-style page from Settings → Create Md. Choose HTML table output when you need a tabular export (the docs note support from v0.2.84 onward).

Where it runs

Web

Browser web app

Use Todolist TreeView in the browser with flows close to the VS Code extension—create a cloud-backed file, open it from the card, and edit in the same tree UI. Hosted app: https://app.aicupa.com/. Site: https://aicupa.com/.

Desktop

VS Code, Windows, and macOS

VS Code: Marketplace — saber2pr.todolist. Windows / macOS: pick an archive from GitHub Releases (example latest: win-v0.2.223, mac-v0.2.223).

Self-host

Docker and webhooks

Run the published image saber2pr/todolist-app:master, expose port 3000, then point a Webhook field to http://<host>:<port>/api so edits sync to your deployment.

Chrome

Chrome extension (experimental)

Load the repository as an unpacked extension in Developer Mode. The documentation labels this path experimental—expect manual updates and rough edges.

TodoList Pro

Pro

Versioned local backups

The public feature notes describe encrypted local backups with per-edit history down to the second, plus rollback—called out as a Pro-only capability. Desktop upgrades are documented separately from the free extension path.

How it works

Start fast, then deepen: pick a client, load a tree, layer calendars, exports, or AI when you need them—the documentation walks through each flow with screenshots.

Pick a client

Use the web client at app.aicupa.com, the VS Code extension from the Marketplace, or native Windows / macOS .tar.gz builds—see Platforms for direct downloads and Releases for the full list. Docker self-hosting is optional. Marketing site: aicupa.com. Each path shares the same TreeView model.

Open or create a .todo file

In the editor or web host, open a *.todo file (or create a cloud file in the web UI) to load the hierarchical editor.

Shape work, then add power tools

Break tasks down, set time ranges, use timeline or sorting when the list grows, and wire exports or AI only when your process calls for it. Optional Pro backups add local version history for subscribers.
